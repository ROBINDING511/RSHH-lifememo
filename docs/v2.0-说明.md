# 人生海海 v2.0 说明（基于《编程主session-优化输入.md》）

版本线：**v1.0**=保留主版本(main) · **v1.5**=skills 优化版(unslop+finesse) · **v2.0**=本任务书体验升级（分支 v2.0）。
决策门：产品负责人已确认**全流水线**（B1~B3/B5）。

## 已落地
- **C 录音门控**：首次录音前隐私弹层（用途/存储/可删/不分享没人听）；未同意按钮置灰+鲸鱼静止；麦克风帧先缓冲、ready 后补发（asr 既有 _frameBuf）。
- **D 字幕纪律**：实时字幕默认最近 2 行 + 大字开关 + 看全部；上滑读历史停跟随 + 「回到最新一句」；同轮替换/跨轮保留（asr item 机制）。
- **A3 留白**：「这段不想说」+ 口述命中不想说/跳过 → blanks[]；AI 禁提（analyze/refine prompt 注入）；引导 pick() 排除；安抚文案。
- **A6 句级确认**：整理稿逐句「像我说的/不像」；不像→展开「我来说」输入 + 按住说话纠正；替换 state=user-fixed，原句进 corrections 可还原。
- **A7 追问上限**：pick() 近期已问不重复（storage）；预留 followUpCount 注释。
- **A8 情绪保护**：敏感词不追问不整理 + 温和话术 + 「先歇一歇」（草稿已落）+ markBlank(情绪保护)。
- **A9 状态透明**：复核卡状态条说人话（顺句子/顺好了/没顺成原话没少），不出现 AI/模型/生成。
- **A10 三视图**：整理稿/逐字/疑点标注 大按钮切换；一键还原逐字永远可用。
- **A11 长停顿**：静音只断句不结束录音；仅松手/60s 上限结束（核查+注释）。
- **A12 漏斗 L4**：本地 L4_pub(首座冰山)/L4_listen(首次回听)。**阈值：L4<50% 需介入**（运营参考）。
- **B1 数据模型**：icebergs 新增 rawText/lines/sentences/doubts/corrections/blanks/versions/refineState；旧冰山无字段走 splitSentences 不报错；asr getLines 句级时间戳(estimated)。
- **B2 refine 云函数**：四步(提取疑点→轻整理→独立审查→修订)；短句降级；≤4 次 LLM；单步 25s；失败不重试；rawText 哈希缓存；异步不阻塞发布。
- **B3 硬校验**：quote 连续子串否则回退逐字；[AI补充] 整稿拒绝；Luhn 银行卡脱敏（adapted yitan MIT）。
- **B4 红字点改**：疑点红字下划线可点→半屏 sheet（整句上下文+▶听原声+候选标"同音/按算术"+保留原说+自己写+先不改）；替换同步 sentences+lines+corrections，原声不动。
- **B5 精确 seek**：优先 evidence/lines 时间戳，无则字数比例；进度条可拖动+当前/总时长。
- **E 翻书阅读**：长文(>4句或>200字)每页≤4句；上一页/下一页大按钮+左右滑动；大字开关；页码大字；短文单卡；reduced-motion 直切。
