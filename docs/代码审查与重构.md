# 代码审查与重构记录 · 人生海海

> 背景：代码经多轮 LLM 迭代，曾呈"缝合怪"态（死代码、过期注释、重复逻辑、页面巨石）。本文记录审查发现、已做的清理重构、以及结合《竞品与产品哲学研究.md》的优化建议。

## 一、审查发现（重构前）
1. **页面巨石**：`pages/ocean/ocean.js` 839 行，混杂 世界布局 / ASR 会话 / 录音 / 复核 / 发布 / 拖拽 / 导航 七种职责。
2. **死代码**：`BERG_SLOTS`（2D 化后废弃）、`_dbgTimer` 调试残留、`analyzing`+`analyze-mask`（复核改异步后不再置位）、`cancelRecording`（微信式后无入口）、`maxSeconds`（面板不再显示）、`utils/assets.js`+`api.SIZE_FILE`（水彩方案废弃后无引用）。
3. **过期注释**：ocean.js 头部仍写"鸟瞰矢量 P0 / 独立 SVG / 点一下开始"，与实际（2D 插画 / 按住说话）不符。
4. **重复逻辑**：toast/showModal 散落各处、色值硬编码重复；`wx.getWindowInfo` 多处重复调用；世界坐标换算在拖拽/发布各写一遍。
5. **布局与 UI 耦合**：极坐标散点/区域判定/居中偏移等纯计算写在页面里，不可单测。

## 二、已做清理重构
- **新增 `utils/sea.js`**：纯布局逻辑（buildWorld/centerOn/regionAt/stageOfMemory/layoutBergs/layoutMilestones），无 UI 副作用、可单测。
- **新增 `utils/ui.js`**：统一 `toast` / `confirm`（Promise 化二次确认 + 统一 palette），消除散落 showModal 与硬编码色。
- **重写 `ocean.js`**（839→~470 行）：页面只做编排与 setData；布局委托 sea.js；提示委托 ui.js；删除全部死代码与过期注释；拖拽/发布共用 `_worldPoint`/`sea.centerOn`。
- **删除** `utils/assets.js`、`api.SIZE_FILE`、`analyze-mask`(wxml+wxss)、`BERG_SLOTS`、`_dbgTimer`、`cancelRecording`、`maxSeconds`。
- 校验全绿：`node --check`、`xcheck_wxml_js`(0 问题)、`a11y_check`(FAIL 0)、编译通过。
- 行为保持不变（按住说话/续录/拖拽换海/复核/发布/化云）。

## 三、当前架构
```
utils/  life(阶段/节点/生日) sea(纯布局) asr(流式) recorder(录音/拼接) draft(草稿) api(云) ui(提示) base64
pages/  ocean(编排) iceberg(详情/补录) timeline recycle stages(规划) guide(分包)
```
数据流：录音→asr 流式→复核(preview)→publish→api→refreshData→sea.layoutBergs→setData。

## 四、结合竞品的优化建议（按优先级）
1. **数据出口（原则7·最高优先）**：HereAfter 已关停、用户仅邮件取回录音。应加"一键导出全部原声+文字（MP3+Markdown/PDF）"，并把"化云5天飘散"期间家人可"接住"。代码：新增 `utils/export.js` + 云函数打包下载。
2. **原声一等公民（原则3）**：文字作音频索引——复核/详情点某句文字跳对应原声片段（需记录字-时间对齐，asr 已有 sentence 时间戳可扩展）。
3. **问题脚手架（原则2）**：空白页→"一次一个问题"。冰山以问题卡浮现（童年/味道/第一次…），鲸鱼可远程投喂问题。代码：`utils/prompts.js` + ocean 空态改问题卡。
4. **AI 润色三档可回退（原则4）**：复核提供 逐字稿/轻度整理/文学化 三档 + 一键还原；保留方言口头禅。代码：preview 增加 polishLevel + rawText 已存可回退。
5. **家庭协作（原则5）**：鲸鱼(孩子)补录/加问题/补照片/拖拽换海已具雏形；补"新冰山落海通知孩子 + 孩子反应回流"。代码：云函数订阅消息 + 反应表。
6. **隐私默认私有（原则6）**：入家族海需显式确认；语音用途明示。代码：iceberg 增加 visibility 字段 + 分享确认。
7. **重温机制（原则9）**："那年今日"潮汐每日托起一座旧冰山。代码：ocean onShow 选同日旧冰山高亮 + 温和提示。
8. **无障碍验收清单（原则10）**：把适老化做成可打勾 QA（参照 FamilySearch 无障碍标签），已有 a11y_check 扩展为 CI 清单。
9. **温柔删除（原则8）**：飘散给足告别动画而非 toast；化云期间可反悔/被接住（已具5天缓冲，补动画与"接住"）。
10. **代码层面**：为 sea.js/life.js 补单测（纯函数已就绪）；把 asr 会话从 ocean 抽成 `utils/asrSession.js` 进一步瘦身；统一错误上报。

## 五、结论
缝合怪已收敛为"纯逻辑模块 + 薄页面编排"。下一步价值最高的是**数据出口**与**问题脚手架**（竞品验证 strongest），其余按优先级渐进。
