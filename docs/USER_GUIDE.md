# 给妈妈的使用说明

## 记住一句话就够了

**长按小鲸鱼杭航，想说什么就说什么。**

## 它们是什么

- 🐋 **杭航**：小蓝鲸鱼，就是孩子。对着它说话，就像跟孩子聊天
- 🏔️ **冰山**：您说过的每句话，会变成一座冰山，漂在海面上
- 🌊 **海域**：海分成一片一片——童年、结婚、孩子长大……话说得越多，海越热闹

## 怎么用

1. **想说话时**：按住小鲸鱼，开始说（跟发微信语音一样）
2. **说完了**：松开手，字会自动跳出来，看一眼
3. **有错字**：直接在字上改一改
4. **想配照片**：点那个"＋"
5. **没问题了**：点"变成冰山"，这句话就永远留在海上了

## 想看看以前说的话

- 点一下海上的冰山，就能看到当时的话，还能**听听自己当时的声音**
- 右上角点"时间轴"，按年份看全部
- 手滑一滑，海面可以左右移动

## 不小心删错了怎么办

删掉的冰山只是**化成了云**，飘在"云朵"里。点开右上角的云朵，找到它，点"落回海面"，它就回来了。

放心说，说什么都在。
人生海海，山山而川，不过如此。
