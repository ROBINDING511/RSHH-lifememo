# 给妈妈的使用说明

## 记住一句话就够了

**想说什么，按住屏幕下面的蓝色按钮说；说完了，再点一下。**

## 它们是什么

- 🐋 **杭航**：小蓝鲸鱼，就是孩子。对着它说话，就像跟孩子聊天
- 🏔️ **冰山**：您说过的每句话，会变成一座冰山，漂在海面上
- 🌊 **海域**：海分成一片一片——童年、结婚、孩子长大……话说得越多，海越热闹

## 怎么用

1. **想说话时**：按住下面那个蓝色的「点这里说话」，开始说
2. **说完了**：点一下「说完了」，字会自动跳出来，看一眼
   （也可以直接**长按小鲸鱼杭航**说话，跟发微信语音一样，松手就结束）
3. **有错字**：直接在字上改一改，改不对也没关系
4. **没听清**：可以先只把声音存下来，以后再补字
5. **想配照片**：点那个「加照片」
6. **想先听听**：点「听听我自己的声音」
7. **没问题了**：点「变成冰山」，这句话就永远留在海上了

## 想看看以前说的话

- 点一下海上的冰山，就能看到当时的话，还能**听听自己当时的声音**
- 下面的「时间轴」，按年份看全部
- 手滑一滑，海面可以左右移动；点一片海域可以放大看

## 说错话、按错了怎么办

- 录音时点「不录了」→ 会先问您要不要**存下来**，不会直接扔掉
- 说了一半来电话、微信切走了 → 您说的话**自动存进草稿**，回到海面上会看到
  黄条提示「有 N 段话没存好」，点「找回来」就能接着存
- 发布时网络不好没存上 → 也会自动进草稿，不会白说

## 不小心删错了怎么办

删掉的冰山只是**化成了云**，飘在「云朵」里。点开「云朵」，找到它，
点「落回海面」，它就回来了。

放心说，说什么都在。

人生海海，山山而川，不过如此。
