# 排版与交互优化 · 三方案（只谈布局/交互/图标，不谈配色）

> 目标：先定"骨架"（元素位置、手势、层级、图标语言），配色下一步再套。
> 每方案含：① 主界面山/海/船优化 ② 小船菜单的 Icon/Bubble 优化 ③ 按钮位置审计＋交互逻辑＋具体变化。

## 方案 A · 拇指热区（单手优先）
**设计逻辑**：Fitts 定律＋拇指热区。所有高频动作落在屏幕下半"拇指弧"内；上半只放"看"的内容，不放"点"的内容。一屏一primary动作。

### ① 主界面 山/海/船
- 海平线固定在屏高 **38%**（现在 20% 太靠上，天空占比大、内容区被压）。
- 雪山带放在 **45%–75%** 视觉中心带；最新山始终居中偏左（焦点），旧山向右退晕（深度=透明度+尺寸递减，形成"时间纵深"）。
- 小船从"海上随机漂"改为**锚定在最新山右下方的拇指弧边缘**（右下 1/4），既是 companion 又是菜单入口，不再满屏漂导致点不到。
- 月亮/星保留天空区但**降对比**（不抢焦点）。

### ② 小船菜单 Icon/Bubble
- 菜单改**底部半屏 sheet**（从船的位置向上展开，锚定船），不再跳整页 → 保持"还在海上"的空间感。
- sheet 顶部一排 **4 个 56px 线性 icon**（关于我/我的海/AI+/家人），icon 统一 2px 描边、24px 网格、圆角端点；文字标签 12px 在 icon 下。
- Bubble 改**船口小气泡**（最大 2 行、280px 宽、尾指船），只在"有话要说"时出现（20s 节奏保留），不再有大卡片挡海。

### ③ 按钮位置审计＋交互变化
| 元素 | 现在 | 改为 | 理由 |
|---|---|---|---|
| 录音主钮 | 底部居中 pill | 底部居中**加宽到 86% 宽、96px 高** | 拇指最大热区，误触率↓ |
| 右滑锁定 | 手势隐式 | 主钮**右 1/4 内嵌"锁"icon 区**，滑入即锁 | 手势可见化，可发现性↑ |
| 上滑取消 | 手势隐式 | 主钮上方 8px 处浮现"↑ 取消"微标签（仅按住时） | 手势 affordance |
| 船/菜单入口 | 海上漂 | 右下锚定＋**长按=直接录音**（副入口保留） | 可预测位置 |
| 时间轴/回收站 | 菜单深处 | 天空区**左下两枚 40px 幽灵 icon**（半透明、不抢焦点） | 高频次级动作提层 |
| 草稿/回执 | 顶部条 | 顶部**单行 toast 流**（4s 自动消） | 不占布局 |
- 交互逻辑：**一屏一primary**；所有破坏性操作二次确认仅一次；所有手势有视觉 affordance；反馈 <100ms（震动+色变）。
- Icon 变化：统一线性 2px/24 网格；船=菜单、锁=免按住、↑=取消、云=回收、书=时间轴、人=关于我。
- 排版变化：信息密度上疏下密；天空留白≥38%；卡片圆角统一 20px；字号阶梯 12/14/17/22/34。

## 方案 B · 画卷横叙（沉浸滚轴）
**设计逻辑**：把"时间轴"变成空间隐喻——横向滚动=人生推进；界面 chrome 最小化，内容即界面（immersive scroll）。手势统一为"横滚=时间、按住=记录、右滑=锁定"。

### ① 主界面 山/海/船
- **全屏无 chrome**：海平线 30%，雪山按年代分"幕"，每幕一屏宽；幕与幕之间用**海色渐变过渡**（不是硬切）。
- 小船**永远在画面中线偏右**领航（随滚动保持相对位置），最新山在船头方向 → "船带着你走向新记忆"。
- 每幕顶部一枚**年代旗标**（小旗+年份），替代现在的大字海名标签。
- 月亮固定天空右上（不随滚），星随滚轻微视差（0.3x）→ 深度感。

### ② 小船菜单 Icon/Bubble
- 菜单改**右侧抽屉**（从右缘滑入 78% 宽），icon 竖排 rail（48px）＋展开二级列表；抽屉半透明磨砂保持海面可见。
- Bubble 改**沿滚轴的里程碑气泡**：停在某幕时，船口浮出该幕一句话摘要（1 行），滚动即消 → 气泡成为"导读"而非通知。

### ③ 按钮位置审计＋交互变化
| 元素 | 现在 | 改为 | 理由 |
|---|---|---|---|
| 录音主钮 | 底部居中 | **右缘竖条 hold-bar**（72px 宽、40% 高、垂直居中偏下） | 横滚时右手拇指自然落在右缘；不遮海 |
| 锁定 | 右滑 | hold-bar **上滑=锁定**（与横滚正交，不冲突） | 手势正交化 |
| 取消 | 上滑 | hold-bar **下滑=取消** | 同上 |
| 菜单 | 点船 | 点船=右抽屉；**左缘左滑=快捷时间轴** | 边缘手势=导航 |
| 回收站 | 菜单内 | 抽屉底部 icon | 收纳 |
| 回执 | 顶部条 | **船口单行气泡**（与导读气泡同槽位复用） | 槽位复用减元素 |
- 交互逻辑：**边缘=导航、中心=内容、右缘=记录**；所有手势正交（横滚/竖滑/按住）互不冲突；滚动惯性+幕吸附（snap）。
- Icon 变化：竖 rail 用 28px 面性 icon（抽屉内对比强）；主界面仅 2 枚幽灵 icon（左下时间轴、右下船）。
- 排版变化：无卡片堆叠；文字只出现在旗标/气泡/抽屉；主界面字级仅 12/17/28 三档；留白=海本身。

## 方案 C · 卡片堆栈（任务流）
**设计逻辑**：progressive disclosure＋任务流。每屏只解决一件事；主界面=“今天”任务卡堆栈；菜单=居中模态栈；icon=大按钮化（icon+文字一体，48px 触区）。适合"不想学手势"的用户。

### ① 主界面 山/海/船
- 海退为**顶部 40% 头图**（静态景，山/船作为插画元素而非交互对象）；船在头图内**居中偏右**，点船=开菜单模态。
- 头图下缘**负 margin 叠"今天"卡**（奶油色保留）：卡内=一句问候＋"按住说"主钮（卡内全宽）。
- 其下堆栈：`未完成草稿`卡（有才出现）→ `最近一座山`卡（点进详情）→ `人生节点`卡（按住聆听）。
- 雪山交互从头图移到"最近一座山"卡缩略图 → 主界面不再需要横滚（横滚保留在详情/时间轴页）。

### ② 小船菜单 Icon/Bubble
- 菜单改**居中模态栈**：2×2 大 icon 按钮（关于我/我的海/AI+/家人），每枚=48px icon＋14px 文字＋88px 触区；下方二级为列表行（左 icon 右 chevron）。
- Bubble 改**模态顶部横幅**（1 行、可点展开），不再锚船 → 位置稳定、不挡内容。
- 声音克隆开关=列表行右 switch（48px），行整行可点。

### ③ 按钮位置审计＋交互变化
| 元素 | 现在 | 改为 | 理由 |
|---|---|---|---|
| 录音主钮 | 底部悬浮 | **"今天"卡内全宽钮**（随卡滚动但 sticky 底） | 动作与上下文同框 |
| 锁定/取消 | 手势 | 主钮**长按中浮现左右两个半圆按钮**（锁/取消） | 手势按钮化，零学习 |
| 菜单 | 点船跳页 | 点船=居中模态（不离开主界面） | 空间连续 |
| 时间轴/回收站 | 菜单二级 | 模态 2×2 下方**两枚行按钮** | 提层 |
| 回执 | 顶部条 | 模态/卡顶部**内联横幅** | 上下文内反馈 |
- 交互逻辑：**一卡一任务**；模态栈最多 2 层；所有手势有按钮等价物（可不用手势完成全部操作）；返回=下滑模态/卡。
- Icon 变化：面性+线性混合 32px／2px 描边；每 icon 必带文字标签（不靠猜）。
- 排版变化：垂直堆栈、8px 栅格、卡间距 12px；字号 12/14/17/22/34；触区≥88px；左对齐为主（阅读动线）。

## 三方案对比（选型用）
| 维度 | A 拇指热区 | B 画卷横叙 | C 卡片堆栈 |
|---|---|---|---|
| 学习成本 | 中（手势+affordance） | 中高（边缘手势） | 低（全按钮化） |
| 沉浸感 | 中 | 高 | 低 |
| 单手效率 | 高 | 高 | 中 |
| 长辈友好 | 中 | 中低 | 高 |
| 与现有代码改动量 | 中 | 大 | 中 |
| 适合 | 平衡首选 | 强调"人生画卷"叙事 | 强调零学习/适老 |

**推荐**：A 为骨架（拇指热区+底部 sheet），吸收 C 的"手势按钮等价物"与 B 的"幕吸附+旗标"，形成 A+ 混合；若你更爱沉浸选 B，更爱零学习选 C。
