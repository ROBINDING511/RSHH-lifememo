改了什么对照你提的三条

  • 不具象、更小：鲸鱼和冰山全部改为 SVG 矢量简笔造型（冰山 3-4 个色面、鲸鱼两色平涂），尺寸缩小约一半。
  • 真正在冰山间游弋：鲸鱼图层夹在"远景冰山"和"中/近景冰山"之间，巡航时会从中景冰山后面穿过，被挡住再游出来——深度穿插，不是贴图叠贴图。
  • 正经前端：零位图。海面是 CSS 渐变、浪纹是 SVG 描边线、鲸鱼摆尾/划鳍/浮沉、冰山摇曳、飞鸟扇翅全部是 CSS keyframes（只动 transform/opacity），DOM 就是最终小程序 WXML 的结构。

怎么玩

  1. 先看 15 秒：鲸鱼从右侧出发向左游，钻到中景冰山后面，到左侧转身（身体侧转压扁再展开），再游回来。
  2. 按住大按钮"说话"：字一个个蹦出（95 毫秒/字）+ 计时。
  3. 松手复核 → 点"对，化成冰山"：一座新冰山落进中景层（和鲸鱼同深度，之后鲸鱼也会从它后面游过）；点"先存起来"落草稿。
