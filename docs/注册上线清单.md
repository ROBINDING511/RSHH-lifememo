## 三、服务器域名白名单

**打开链接：https://mp.weixin.qq.com** （同一个后台）
→ 左侧菜单「开发管理」→「开发设置」选项卡 → 下拉到「服务器域名」区块 → 点「修改」
（需管理员扫码确认修改）

| 类型 | 填写内容（整行复制） |
|---|---|
| **socket 合法域名** | `wss://token-plan.cn-beijing.maas.aliyuncs.com` |
| request / uploadFile / downloadFile | 留空不填 |

说明：
- `request 合法域名` 可留空（LLM 分析走云函数中转，不经小程序直连；云存储走微信自带域名，无需配）。
- 域名每月限改 5 次，一次配齐。
- 配置后约 5–10 分钟生效；生效前真机测试可在开发者工具勾「不校验合法域名」，但**提审前必须配好**。
- 即使忘记配也不会崩：流式连不上时会自动改走 `transcribe` 云函数兜底转写（慢一点但能用）。

## 四、用户隐私保护指引

**打开链接：https://mp.weixin.qq.com** （同一个后台）
→ 点左下角账号头像 →「账号设置」→「基础设置」里的「服务内容声明」模块
→「用户隐私保护指引」→ 点「去完善」
（官方路径原文：账号设置 - 服务内容声明 - 用户隐私保护指引 - 去完善）

这是提审必查项。进入后按下面对照勾选并粘贴文案：

### 勾选的接口/权限（只勾实际用到的）
| 接口 | 用途说明（可直接粘贴） |
|---|---|
| 麦克风（`scope.record`） | 长按鲸鱼录音，将语音转成文字并保存原始语音，用于生成回忆 |
| 选中的照片或视频信息（`wx.chooseMedia`） | 用户主动为回忆添加照片时读取所选图片 |
| 微信昵称/头像 | 不收集（本小程序不获取用户资料，如无此项则跳过） |

### 隐私声明正文（粘贴到说明栏）
> 本小程序为个人回忆记录工具。录音与照片仅存储于腾讯云开发为每位用户创建的独立存储空间，默认仅用户本人可见，不对外公开、不用于商业用途；语音转文字由阿里云百炼提供，音频仅用于当次识别。我们不收集身份、位置、通讯录等其他个人信息。删除数据：在微信「设置-小程序」中删除本小程序，或联系开发者清空云端数据。

提交后等待微信审核隐私指引（通常几小时内通过），**通过后才能提交代码审核**。
