# 人生海海 · 当前系统现状（模拟基准 v2.0，分支 v2.0）

> 供 10 人模拟操作实录使用。所有界面/文案/流程以本文为准，不得虚构不存在的功能。
> 载体：微信小程序。主色墨青 #1F6478，暖纸底。适老化：正文≥34rpx、转写48rpx、触控≥88rpx。

## 0. 首启与引导
- 首次打开进入海洋主界面（水平夜海滚轴场景：夜空星+弯月；山=回忆，新红→旧深蓝；金鱼杭航红身米色喷水；帆船米帆红身）。
- 若未设生日：金鱼口中冒出气泡「请问您出生于哪一年？」+ 回答建议 chips(1950/1960/1970/1980/1990年) + 「滚轮选年份」picker + 「跳过」。点 chip 或滚轮即记录；跳过后气泡消失。
- 称呼不在引导里：点金鱼→杭航主菜单→「我的海」二级→「怎么称呼你」input(type=nickname 可一键填微信昵称)+「记好了」。
- 无设置页、无追问式调研、无鲸鱼语音、无录音前同意弹窗（录音同意走微信官方隐私授权+系统麦克风权限）。

## 1. 海洋主界面（首页）
- 水平滚轴：向左滚=时间越年轻，向右滚=越久远；双指捏合缩放(0.6–2.5)，用户视角会话内保持、仅重启重置。
- 山=回忆：高度∝留言量；点山→冰山详情。新山插红旗5分钟。
- 底部大按钮「按住 说话」：按住=录音+实时字幕面板；松手=发送进复核卡；上滑=取消(落草稿)。快速点按也会停(不会卡住)。
- 实时字幕面板：最近2行+「大字」+「看全部」+上滑停跟随+「回到最新一句」；状态提示「正在连线，字马上就来」/「字暂时不出来，别急，松手会自动整理好」。
- 空态(无回忆)：深色胶囊「想说什么，就说给杭航听 / 按住下面的青色按钮，说说看 / 换一个问题」。
- 草稿条(有未存草稿)：「有 N 段话没存好」+「找回来」。
- 点金鱼→杭航主菜单；长按金鱼=副录音入口。

## 2. 复核卡（松手后底部抽屉）
- 顶部 grip 可下拉关闭(=自动存草稿)；右上 ❌=化成云(进云朵可找回/可删)。
- 正文 textarea：AI 标题直接加在文字上方(不可关,可点改)；默认保留原话。
- 照片九宫格裸「＋」添加(≤9)，点照片预览，×删除(二次确认)。
- 「哪片海」cell→actionSheet 选海(什么时候==哪片海,只选一次)；听到年份/岁数只读提示「听到 1963年·14岁，落在」自动归海(8岁→童年;文本出生年识别为生日)。
- 情绪保护：命中敏感词(不想活/过世/重病等)→不整理+温和话术+「先歇一歇」(落草稿)。
- 状态条：「正在帮您顺句子……只顺了顺句子，您说的一个字都没添」/「顺好了，看看像不像您说的」/「这次没顺成，您的原话一个字没少」。
- 底部按钮：「存草稿」(点了就存,不弹窗) / 「变成冰山」(发布)。
- 续录：复核卡内「没说完？按住继续说」追加文字+音频段。

## 3. 杭航主菜单（点金鱼）
- 一级：我的海 / 回忆梳理 / 家人共建 / 声音；点一级展开二级(手风琴单开)。
- 我的海二级：怎么称呼你 / 几片海叫什么到几岁(改名/改边界/加一片海/删) / 人生节点=海的开端(加节点=开新海,删=合并) / 你的年纪(生日/年龄/出生年份三选+记好了) / 按住跟杭航说你的划分(语音设边界)。
- 回忆梳理二级：AI文字梳理风格三选(忠实原文/轻度优化·尽量保留原话/口语顺成书面语) / 时间轴 / 云朵。
- 家人共建二级：生成邀请码 / 我是家人填邀请码绑定 / 投喂一个问题给妈妈。
- 声音二级：妈妈的声音克隆(状态+试听+删除) / 允许克隆我的声音(单独同意开关,默认未同意,开启弹敏感信息告知)。

## 4. 时间轴
- 按年分组(年份徽章+虚线+点+卡片)；卡片=四字标题+meta(时间·X之海)；点→详情。隐藏滚动条。

## 5. 冰山详情（翻书阅读）
- 头部：四字标题+meta。
- 三视图大按钮：整理稿/逐字/疑点标注 + 「大字」。
- 长文翻书：每页≤4句，上一页/下一页大按钮+左右滑动+页码；短文单卡。
- 句级确认(整理稿)：每句「像我说的」/「不像」；不像→展开输入+「按住 说话纠正」+「按我说的改」；原句存档可还原。
- 红字点改(疑点)：红字下划线可点→半屏sheet(整句上下文+▶听这一句原声+候选标"同音/按算术"+保留原说+自己写+先不改)。
- 原声：「听听当时的声音」大播放钮+可拖进度条+当前/总时长；点句精确跳转。
- 家人视角：想听/抱抱 反应回流。
- 底部：「继续说 / 补录这段」(主) + 「放个标记」/「化成云」(次)。
- 照片九宫格点看大图。

## 6. 云朵（回收站）
- 「化成云的冰山都在这里，5 天后会完全飘散」；每朵云=标题+meta+「X天后飘散」+「落回海面」(恢复,不弹窗)。
- 打开时自动永久清除超5天的云。

## 7. 家人协作
- 长辈生成邀请码→孩子填码绑定→孩子看长辈的海/投喂问题/点想听抱抱→长辈侧显示「杭航想听/抱抱了 N 次」。
- 投喂的问题优先作为空态提示。

## 8. 声音克隆
- 默认未同意不收集；单独同意后才收集样本；克隆完成→长辈试听「像不像」→像=固化(不再自动克隆)/不像=重克隆；删除=恢复自动克隆。

## 9. 已知痛点/历史问题（模拟时可体现）
- 曾出现：按住变点按(已修)、背景音下载慢(已下线)、引导像调研(已改气泡/菜单)、位图放大糊(已改矢量)、鲸鱼忽大忽小(已修)、8岁归错海(已修)、"没听清"文案(已改温和追问)。
- 仍可能存在：老年人对"按住/上滑/捏合"手势学习成本、气泡建议年份不够细(只有整十年)、滚轮 picker 字小、菜单层级深、四字标题抽象、红字/疑点概念难懂、5天飘散引发焦虑、邀请码流程复杂、克隆同意术语敏感。
